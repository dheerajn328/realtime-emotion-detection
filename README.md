\# Real-Time Emotion Detection



A deep learning based real-time emotion detection system using Python, OpenCV, and TensorFlow/Keras.



\## Features

\- Real-time webcam emotion detection

\- Model training support

\- CK+ dataset support



\## Files

\- realtime\_emotion.py → Main realtime detection

\- training.py → Model training

\- check\_labels.py → Label checking utility



\## Requirements

pip install opencv-python tensorflow keras numpy
